#
# Note what is NOT here: Apache Airflow. The pipeline package deliberately has no
# dependency on the orchestrator (see DECISIONS.md D14) — the DAG is thin glue over
# these modules. That split is what lets the whole test suite run in seconds without a
# scheduler, and what makes "you could run this on Cloud Run Jobs instead of Composer"
# (D9) a real option rather than a claim.
#
